A Girl’s Best Friend

Hypothesis: A secure, user-friendly web application can simplify menstrual health management by accurately tracking cycles, moods, and patterns while providing predictions, reminders, and personalized insights.

Problem Statement

Many women find it difficult to accurately track menstrual cycles, predict upcoming periods, understand mood changes, and maintain long-term health records. Existing solutions often lack personalization, emotional relatability, or secure data handling. This creates confusion, missed patterns, and increased stress in managing menstrual health.

Literature Review / Market Research

Existing menstrual tracking applications mainly focus on basic period logging and predictions. Most lack integrated mood analysis, detailed analytics, or strong security features such as two-factor authentication, limiting user trust and long-term engagement.

Research Gap / Innovation

This project bridges the gap by combining cycle tracking, mood analysis, data visualization, secure authentication, and educational resources into a single personalized platform, offering both emotional support and technical reliability.

System Methodology

Input Data

User-entered menstrual cycle details, mood logs, and personal preferences stored securely.

System Architecture

MERN stack architecture with REST APIs, prediction logic, analytics processing, and secure authentication.

Implementation

Frontend built with React, backend with Express and Node.js, and MongoDB for data storage.
